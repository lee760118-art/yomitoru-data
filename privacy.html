プライバシーポリシー

アプリ「ヨミトル - サイバー被害ニュース」　制定日：2026年11月11日

ヨミトル（以下「本アプリ」）の運営者（個人開発者。以下「運営者」）は、利用者の個人情報を次のとおり取り扱います。

1. 集める情報

本アプリは、氏名、メールアドレス、位置情報、端末の識別子、利用状況などの個人情報や利用データを集めていません。アカウント登録もありません。広告や利用状況の分析（アクセス解析）のための仕組みも組み込んでいません。

2. ニュースの読み込みについて

本アプリは、ニュースのデータを GitHub Pages（GitHub, Inc. のサービス）から読み込みます。このとき、通信のために端末の IP アドレスなどが GitHub に送られ、GitHub の方針に従って記録されることがあります。詳しくは GitHub のプライバシーに関する声明をご覧ください。運営者がこの記録を利用することはありません。

地図の表示のため、地図用のプログラムを jsDelivr（ファイル配信サービス）から読み込みます。このときも通信のための情報が同サービスに送られることがあります。

3. 端末に保存する情報

通信できないときにも直前のニュースを表示するため、読み込んだニュースのデータを端末の中に保存します。このデータは運営者に送られません。アプリを削除すると消えます。

4. 外部サイトへのリンク

記事の出典リンクを押すと、外部のウェブサイトが開きます。外部サイトでの情報の取り扱いは、各サイトの方針に従います。

5. 第三者への提供

運営者は利用者の個人情報を集めていないため、第三者に提供することもありません。

6. お子さまの利用

本アプリは年齢を問わず使えます。お子さまの個人情報も集めていません。

7. このポリシーの変更

内容を変更する場合は、このページで知らせます。集める情報を増やす場合は、事前にアプリ内でもお知らせします。

8. お問い合わせ

サポートページをご覧ください。
